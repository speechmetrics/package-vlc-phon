VLC media player runtime for Phon
=================================

This folder contains the core libraries and a subset of the plug-ins of
VLC media player @VLC_VERSION@, as released by VideoLAN
(https://www.videolan.org/). Plug-ins Phon does not use were removed;
nothing else was changed apart from library load paths where noted in the
build log.

Phon (https://www.phon.ca) uses it through vlcj to play media files.

VLC is free software released under the GNU GPL and GNU LGPL; see
COPYING.txt and AUTHORS.txt.

Source code for this release of VLC:
https://code.videolan.org/videolan/vlc/-/tree/@VLC_VERSION@

Packaging scripts:
https://github.com/speechmetrics/package-vlc-phon
